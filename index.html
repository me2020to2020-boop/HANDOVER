About this installable version: It opens from its own home-screen icon and works like an app. Your doctors, cases, handover date and handing-over / receiving selections are autosaved on this phone as you work, so closing the app or refreshing no longer loses them — reopen it and everything is restored. Data stays on that phone only: it does not sync between doctors’ phones. To hand over to another doctor, tap Export JSON and send that one file (for example on WhatsApp) — the receiving doctor opens this same link on their phone and taps Import JSON to load the full day without retyping. You can also Download handover sheet (.txt) or Copy summary when you just need a readable copy.

📱 Android — Chrome

  1. Open this page in Chrome.
  2. Tap the ⋮ menu (top right).
  3. Tap Install app or Add to Home screen.
  4. Tap Install / Add — an icon appears on your home screen.
  5. Open it from the icon: it launches full-screen, like a separate app.

🍎 iPhone — Safari

  1. Open this page in Safari.
  2. Tap the Share button.
  3. Scroll and tap Add to Home Screen.
  4. Name it Handover and tap Add.
  5. Open it from your home screen icon.

Daily routine (about 6 cases)

  1. Morning: Add the day’s doctors if they’re new — doctors and cases are autosaved on this phone, so they’re still here if you close and reopen the app. Then add each case with history & endoscopies.
  2. During the day: Add each consultant’s opinion as reviews happen.
  3. Handover: Pick handing-over & receiving doctors, mark each case handed over, then tap Export JSON and send that one file to the receiving doctor — they open this same link and tap Import JSON to load the cases. Or download / copy the sheet for a readable copy.
  4. Next day: Use “Carry unfinished to tomorrow” for cases that stay.
